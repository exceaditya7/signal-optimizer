Smart Traffic Optimizer

Point it at traffic video, draw a region on the road, and get live vehicle counts, tracked IDs and density for that region. YOLOv11 detects cars, motorcycles, buses and trucks, and ByteTrack follows each one.

This is a simulated scene running in your browser. It reproduces what the project's scripts overlay on real video (boxes, IDs, a polygon region, live counts) and does not run YOLO. Occupancy is the share of the region covered by vehicles; the free, busy and heavy thresholds are illustrative.

How a frame becomes a count

  1. 1

    Read video

    data/sample_videos/

    Frames come from the sample videos in the repository.

  2. 2

    Detect

    backend/yolo11n.pt

    The YOLO11 nano weights find cars, motorcycles, buses and trucks in each frame.

  3. 3

    Track

    ByteTrack

    Each detection keeps a unique vehicle ID from frame to frame, so one car is counted once.

  4. 4

    Check region

    data/roi_points.npy

    Vehicles crossing or staying inside the saved ROI polygon are the ones that count.

  5. 5

    Overlay

    traffic_analyzer.py

    Counts, density and tracking markers are drawn on the video in real time.

Run it

1. Install

git clone https://github.com/exceaditya7/signal-optimizer.git
cd signal-optimizer
python3 -m venv backend/venv
source backend/venv/bin/activate
pip install -r requirements.txt
The README says cd smart-traffic-optimizer, but the cloned folder is named signal-optimizer.

2. Draw your region

python backend/roi_test.py
  • Left click add point (min 3)
  • U undo
  • R reset
  • S save
  • Q quit

3. Run the analyzer

python backend/traffic_analyzer.py

Tracks vehicles and counts those inside your saved region, with the overlay drawn live.

Or skip the region

python backend/detector.py

Runs plain full-frame detection with no ROI filtering.

Ideas for what comes next

  • Adaptive signal timing

    Turn per-approach occupancy into suggested green times. This would match the project's name; the repository counts and measures today and does not control signals.

  • Count export

    Log per-class counts per minute to a CSV file for later analysis.

  • Multiple regions

    One polygon per lane or approach, each with its own counts and occupancy.

  • Live camera input

    Read from a webcam or network stream in addition to the sample videos.

These are suggestions, not features of the repository.
